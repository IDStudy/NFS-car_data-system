## 📦 安装指引

> 安装包在 **Release（发行版）** 页面获取：[点击前往](https://github.com/IDStudy/NFS-car_data-system/releases)

### 📱 移动端（Android）

下载 `NFSM-apk.zip`，解压后安装 APK 即可。

> 目前仅支持 Android，iOS 暂无适配计划，敬请谅解。额外支持**数据导出**功能。

### 💻 PC 端（Windows）

下载 `NFSM-exe.zip`，解压后运行 `NFSM车辆查询系统PC端.exe`，可创建快捷方式至桌面。

> 界面更美观，功能更完整，额外支持**车辆海报一键下载**功能，体验更佳。
> ⚠️请勿解压至需管理员权限的目录，否则相关文件会写入失败！

## ✨ 主要功能

- 🔍 **车辆查询**  
  按全金红车/限定/通行证/殿堂耀世四大分类浏览，支持模糊搜索（组别、车辆名、上线时间）。

- 📊 **升阶查询**  
  查看全部车辆升阶情况，支持按升阶时间/上线时间排序。

- 🟣 **紫升金查询**  
  查询紫车升阶为金车的车辆名单，展示组别、车辆名称与升金时间。

- 🧭 **领航员查询**  
  展示领航员品质、上线时间、获取方式、返场时间，特性增益等全部信息。

- 🏁 **赛道成绩查询**  
  按官方赛道/蓝图赛道/火箭飞鼠分类浏览，展示赛道等级与彩标、红标成绩标准，支持模糊搜索。

- 📤 **数据导出**（移动端独有功能）  
  勾选金红车、限定、通行证、殿堂耀世、升阶情况、紫升金、领航员、赛道等任一分类，导出为 TXT 文本或 CSV 表格，支持复制到剪贴板、保存为文件、系统分享。

- 🖼️ **海报下载**（PC端独有功能）  
  一键下载全部已公开的车辆海报，自动跳过已有文件，支持中断续传。

- 🌐 **进入官网**  
  一键直达《极品飞车：集结》官方网站，获取最新游戏资讯。

- 🔄 **更新检查**  
  检查软件是否有最新版本。

### 💡 为什么选择本工具？

- 🏆 **圈内唯一**：目前《极品飞车：集结》玩家圈内唯一一款车辆数据查询工具。
- ⚡ **告别翻推文**：以往查询已上线的车辆信息只能去官方微信公众号翻阅历史推文，十分麻烦，现在打开工具即可秒查，节省大量时间。
- 📤 **数据随手带走**：查询结果可一键复制，或导出为 TXT/CSV 文件，方便整理成自己的表格，也能直接分享给车队好友。
- 📴 **离线可用**：数据本地化，无网络也能畅快查询。
- 🔒 **隐私安全**：本地查询，不收集用户任何个人信息。
- 💯 **永久免费**：无内购、无订阅。
