A single place to look up every vehicle in NFSM — Gold/Red, Limited, Battle Pass, Hall of Fame and Radiant World cars, upgrade stages, Purple→Gold conversions, track time standards, navigator data and car posters — with one-click export of any result.

> **Please note:** the app interface is in Simplified Chinese only. All game data is kept in Chinese as it appears in-game, so this tool is most useful if you can read Chinese terms or match them against in-game names.

---

## 📦 Installation

> Download packages from the **Releases** page: [click here](https://github.com/IDStudy/NFS-car_data-system/releases)

### 📱 Android

Download `NFSM-apk.zip`, unzip it and install the APK inside.

> Android only for now; there is no iOS build and none is planned. Adds the **data export** feature.

### 💻 Windows (PC)

Download `NFSM-exe.zip`, unzip it and run `NFSM车辆查询系统PC端.exe`. You can create a desktop shortcut.

> Cleaner UI and the full feature set, plus **one-click car poster download**.
> ⚠️ Do not unzip into a directory that requires administrator privileges, or the app will fail to write its local files.

## ✨ Features

- 🔍 **Vehicle lookup**
  Browse by four categories — All Gold/Red, Limited, Battle Pass, Hall of Fame / Radiant World. Fuzzy search across class, car name and release date.

- 📊 **Upgrade lookup**
  See the upgrade stage of every car; sort by upgrade date or release date.

- 🟣 **Purple → Gold lookup**
  Lists the purple-tier cars that can be upgraded into gold tier, with class, car name and conversion date.

- 🧭 **Navigator lookup**
  Rarity, release date, acquisition method, rerun date, trait bonus and full effect description for every navigator.

- 🏁 **Track time standards**
  Browse Official, Blueprint (player-made) and Rocket Flying Squirrel courses. Shows track grade plus the Colour Badge and Red Badge target times, with fuzzy search.

- 📤 **Data export** (Android only)
  Tick any of the categories — Gold/Red, Limited, Battle Pass, Hall of Fame / Radiant World, upgrade stages, Purple→Gold, navigators, tracks — and export as TXT or CSV. Copy to clipboard, save to a file, or share via the system share sheet.

- 🖼️ **Car poster download** (Windows only)
  One click downloads every released car poster, skips files you already have, and resumes interrupted downloads.

- 🌐 **Official website**
  Jump straight to the official Need for Speed: Assemble site for the latest news.

- 🔄 **Update check**
  Checks whether a newer version of the tool has been released.

### 💡 Why use this tool?

- 🏆 **The only one of its kind** — the only vehicle data tool in the NFSM community.
- ⚡ **No more digging through old posts** — vehicle info used to mean scrolling back through the official WeChat account; now it is one search away.
- 📤 **Take your data with you** — copy any result or export it to TXT/CSV, ready for your own spreadsheet or to share with your crew.
- 📴 **Works offline** — data is stored locally, so lookups work without a connection.
- 🔒 **Privacy-safe** — everything runs locally; no personal data is collected.
- 💯 **Free forever** — no in-app purchases, no subscriptions.

## ⚠️ Notes

- **Data sources** — all data comes from in-game or officially published information. Updates may lag behind the game for reasons beyond our control.
- **Network** — a connection is only needed on first launch after installing, or when the data updates. Day-to-day lookups and exports work offline.
- **Feedback** — open an [Issue](https://github.com/IDStudy/NFS-car_data-system/issues) or leave a comment on Douyin. Please include **screenshots and a detailed description** so it can be fixed quickly.

## 📖 Terminology

Some in-game terms are hard to translate, so here is how this README maps them:

| Chinese | English used here | Meaning |
|---|---|---|
| 金车 / 红车 | Gold / Red cars | The two top rarity tiers |
| 限定 | Limited | Cars only obtainable from time-limited gacha pools |
| 通行证 | Battle Pass | Cars tied to the paid season pass |
| 殿堂 | Hall of Fame | Tag for gold-tier cars that require heavy spending |
| 耀世 | Radiant World | Tag for red-tier cars |
| 紫升金 | Purple→Gold | Purple-tier cars that upgrade into gold tier |
| 二阶 / 2 阶升金 | Stage 2 | One upgrade applied to a base car; for purple cars the result is a gold car (same as Purple→Gold) |
| 10 级专家 | Expert upgrade | Separate upgrade system, Lv.0 → Lv.10; stronger, costs far more |
| 领航员 | Navigator | Co-driver companion that grants stat and passive bonuses |
| 彩标 / 红标 | Colour Badge / Red Badge | Lap-time standards; the Colour Badge target is the harder one |
| 官方赛道 / 蓝图赛道 / 火箭飞鼠 | Official tracks / Blueprint tracks / Rocket Flying Squirrel | Track categories: official tracks, player-made tracks, and the jetpack-character game mode |
| 组别 | Class | Vehicle class: Sport / Classic / Petrol / Hybrid (some cars count as two) |
| 返场 | Rerun | A limited-release car being made available again |
